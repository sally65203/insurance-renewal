V2.2 安裝及資料安全檢查

正在檢查開啟環境…

請從固定 HTTPS 網址使用 Safari「分享 → 加入主畫面」。安裝後請固定從主畫面圖示進入。主畫面 App 與 Safari 網頁的資料可能彼此獨立，請用 JSON 備份移轉。請先以測試保單確認關閉重開後仍存在，且 JSON 能還原，才輸入正式資料。

iCloud Drive 手動備份

按「下載備份」後，透過 iPhone 分享／儲存到「檔案」→ iCloud Drive。備份包含保單紀錄及已附加的 PDF；還原會取代目前資料。

建議每次新增或修改重要保單後，立即下載 JSON 備份並存到 iCloud Drive。

手機使用提醒：HTML 檔直接在 iPhone「檔案」中開啟時，不同開啟方式可能有不同的儲存空間，且資料可能被系統清除。JSON 備份是主要保護措施；CSV 僅供核對，不包含 PDF，也不能用來還原本系統。目前仍需網路載入 PDF、Excel、OCR 元件。
重要：本測試版資料存於目前瀏覽器的本機儲存空間，清除網站資料可能遺失紀錄。備份尚未加密，含個資，請妥善保管。它不會自動同步至 iCloud，也不保證跨裝置自動共用。
